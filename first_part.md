# 1. Чем git pull отличается от git fetch?

git pull получает информацию об изменениях в репозитории с гита и сразу одобавляет в ветку. git fetch также получает изменения с гита, но не меняет текущую ветку

# 2. Чем в linux отличается soft link от hard link? Какое поведение будет при удалении файла оригинала? Можно ли создать hardlink на директорию?

soft link - ярлык, ссылка на какой-либо файл или каталог. hard link - еще одно имя для того же inode. При удалении файла оригинала soft link станет нерабочей ссылкой на файл-оригинал, hard link продолжит работать пока данные inode не пропадут. Hard link на директорию создавать нельзя, потому что это мжет привести к циклам в файловой системе, нарушению логики.

# 3. Как проверить сетевую доступность между двумя linux машинами?

Через ping проверить по icmp протоколу. Через nc проверить доступность конкретного порта. Проверить на машине какой порт она слушает - через ss
 
# 4. На каких компонентах Linux основана контейнеризации в Docker?

Docker использует механизмы ядра Linux, прежде всего namespaces для изоляции и cgroups для ограничения ресурсов. Также используются capabilities, seccomp и слоистые файловые системы как Overlay filesystem

# 5. Почему вместо "COPY . . / RUN npm install" рекомендуют делать "COPY package.json / RUN npm install / COPY . ."

Чтобы отделять редко меняющиеся зависимости от часто меняющегося исходного кода, чтобы эффективнее использовать Docker build cache.

# 6. Могут ли два контейнера внутри одного пода в Kubernetes слушать один и тот же порт?

Не могут, так как все контейнеры в одном поде имеют один и тот же namespace, ip. 

# 7. Какие виды JOIN знаете и чем они отличаются?

INNER JOIN выбирает строки у которых есть совпадения по заданному условию
LEFT JOIN- выбирает записи только из левой таблицы, из правой только строки которые соврпадают по условию
RIGHT JOIN - то же что и LEFT JOIN, но на правую таблицу
FULL OUTER JOIN (FULL JOIN) - строки из обеих таблиц, где есть совпадения - объединяет. где нет совпадений - null
CROSS JOIN - каждая запись из первой таблицы комбинируется с каждом записью из второй таблицы

# 8. Что такое having в SQL запросе? Чем отличается от where?

WHERE фильтрует отдельные строки до группировки, HAVING фильтрует группы после GROUP BY.
